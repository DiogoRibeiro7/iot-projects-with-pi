# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and releases use semantic version tags matching the version declared in
`pyproject.toml`.

## [Unreleased]

### Added

- Tagged GitHub release automation with wheel and source-distribution artifacts.
- Release tag and artifact metadata validation.

## [0.1.0] - 2026-10-06

### Added

- Typed Raspberry Pi hardware abstractions with hardware-free simulation.
- Weather-station, home-automation, and smart-agriculture reference projects.
- SQLite persistence, structured observability, runtime health state, and
  retained MQTT health publishing.
- Local MQTT messaging and optional cloud telemetry abstractions.
- Durable SQLite telemetry outbox with restart-safe replay.
- Irrigation actuator safety guardrails.
- Shared TOML/environment/CLI runtime configuration.
- Raspberry Pi Zero 2 W profiling and low-resource guidance.
- Native systemd deployment profiles and production Docker image.
- MkDocs Material documentation published through GitHub Pages.
- Real Mosquitto and container smoke tests in CI.
